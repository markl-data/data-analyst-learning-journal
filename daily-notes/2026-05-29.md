## Key concepts I want to remember
- GROUP BY = pivot table expressed in code
- WHERE filters rows BEFORE grouping; HAVING filters groups AFTER
- Every SELECT column must be in GROUP BY or wrapped in an aggregate
- COUNT(*) vs COUNT(column) vs COUNT(DISTINCT column) — three different things
- Always alias your aggregates with AS for readable output
