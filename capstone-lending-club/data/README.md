# Data folder

Data files are excluded from Git (see .gitignore) due to size.

## Source

Kaggle: Lending Club dataset (2007-2018)
https://www.kaggle.com/datasets/wordsforthewise/lending-club

## Files needed

Download the ZIP from the Kaggle link above and extract:
- `accepted_2007_to_2018Q4.csv` (~1.55 GB) — required
- `rejected_2007_to_2018Q4.csv` — not used in this analysis

## Placement

Save the accepted CSV to this folder:
`capstone-lending-club/data/accepted_2007_to_2018Q4.csv`
